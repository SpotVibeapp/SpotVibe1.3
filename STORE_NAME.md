# Store name — SpotVibe - Find Your Vibe

Plain **SpotVibe** is already taken on the Apple App Store and Google Play
by another company. Do not submit this app under that bare name.

| Surface | Use |
|---|---|
| App Store name | `SpotVibe - Find Your Vibe` |
| Play listing title | `SpotVibe - Find Your Vibe` (26 characters, under the 30-character cap) |
| Home-screen label (Android `android:label`, iOS `CFBundleDisplayName`) | `SpotVibe - Find Your Vibe` |
| Android package / iOS bundle id | `app.spotvibe` (unchanged) |
| In-app wordmark and legal name | SpotVibe is fine inside the product |

Checklists that must repeat this at submit time:

- `APPLE_STORE_CHECKLIST.md`
- `PLAY_APP_CONTENT.md`
- `IOS_RELEASE_TODO_BLAKE.md` (App Store Connect create-the-app step)

This file does not file a trademark and does not claim the bare name is
available. If a reviewer asks for a shorter home-screen label later, keep
the store listing title as `SpotVibe - Find Your Vibe`.
