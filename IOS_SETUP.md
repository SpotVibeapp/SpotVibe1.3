# SpotVibe — iOS Setup (VS Code/Windows → Mac/Xcode)

How to get from a fresh GitHub clone on your Mac to a running/uploadable iOS
build. The Dart code is 100% shared with Android — only the native iOS chrome +
secrets need attention. See also `APPLE_STORE_CHECKLIST.md` for the store side.

> **Golden rule:** always open **`ios/Runner.xcworkspace`** in Xcode — NEVER
> `Runner.xcodeproj`. The workspace is what includes CocoaPods.

---

## 1. First-time clone → build (the happy path)
```bash
git clone https://github.com/SpotVibeapp/SpotVibe1.3.git
cd SpotVibe1.3
git checkout arena/01a07f45-spotvibe1-3   # this session's branch
flutter pub get
cd ios && pod install && cd ..
open ios/Runner.xcworkspace
```
Flutter/CocoaPods regenerate the machine-specific stuff automatically
(`Pods/`, `.symlinks/`, `.dart_tool/`, Flutter ephemeral files). Their absence
from Git is expected — they're correctly gitignored.

Quick device run from the CLI:
```bash
flutter devices
flutter run --dart-define-from-file=secrets.json
```

---

## 2. What you MUST add on the Mac (not in Git — by design)

### a) Firebase iOS config — REQUIRED ⚠️
`GoogleService-Info.plist` is gitignored (it's a secret), so it's NOT in the
repo. iOS won't connect to Firebase until you add it:
1. Firebase Console → Project **spotvibe-cfa08** → Add app → **iOS**.
2. iOS bundle ID: **`app.spotvibe`**.
3. Download **`GoogleService-Info.plist`**.
4. In Xcode, drag it into the **Runner/** group (check "Copy items if needed",
   target = Runner).

### b) secrets.json — copy it over manually
Same file you use on Windows. Not in Git. Build with:
```bash
flutter build ipa --release --dart-define-from-file=secrets.json
```
Make sure it contains the iOS keys too:
- `REVENUECAT_APPLE_KEY=appl_...`   (from RevenueCat → API Keys, iOS app)
- `ADMOB_BANNER_IOS=ca-app-pub-.../...`  (real iOS banner unit, when ready)
- plus the shared keys already used on Android (rotated Ticketmaster key, etc.)
- Do NOT include `REVIEWER_PREMIUM_EMAIL` in a public production build.

### c) Signing & Capabilities — set in Xcode (never in Git)
Xcode → **Runner** target → **Signing & Capabilities**:
- Select your **Apple Developer Team**.
- Confirm **Bundle Identifier = `app.spotvibe`**.
- Add capabilities: **Sign in with Apple**, **In-App Purchase**, and
  **Push Notifications** (only if you enable push on iOS; needs an APNs key).

### d) Real AdMob iOS App ID
`ios/Runner/Info.plist` currently has a **TEST** `GADApplicationIdentifier`.
Replace it with the real iOS AdMob app id before an iOS ads build, and add the
**SKAdNetworkItems** list (Google publishes the identifiers to paste in).
`NSUserTrackingUsageDescription` (ATT prompt) is ALREADY present.

---

## 3. What is NOT in Git (don't panic when it's missing)
Regenerated by tooling — leave gitignored:
- `ios/Pods/`, `ios/.symlinks/`, `ios/Flutter/Flutter.framework`,
  `ios/Flutter/ephemeral`, `ServiceDefinitions.json`, `*.xcuserdata`
Secrets / signing — add manually, never commit:
- `GoogleService-Info.plist`, `secrets.json`, certificates, provisioning
  profiles, `key.properties` (Android).

---

## 4. Common first-build snags & fixes
- **`pod install` fails / out of date:** `cd ios && pod repo update && pod install`.
- **Deployment target error** from a plugin (Firebase/purchases_flutter/
  google_mobile_ads): open `ios/Podfile`, set `platform :ios, '13.0'` (or higher
  as the error requests), then `pod install` again.
- **"Module not found" / stale build:** in Xcode, Product → Clean Build Folder
  (⇧⌘K), or `flutter clean && flutter pub get && (cd ios && pod install)`.
- **Signing errors:** confirm the Team is selected and the bundle id matches an
  App ID in your Apple Developer account.
- **Wrong file opened:** if pods seem missing, you probably opened
  `Runner.xcodeproj` instead of `Runner.xcworkspace`.

---

## 5. Build & upload
```bash
flutter build ipa --release --dart-define-from-file=secrets.json
```
Then upload the `.ipa` (in `build/ios/ipa/`) via **Transporter** or from Xcode
(Product → Archive → Distribute App), and submit in **App Store Connect**.

---

## 6. Keep both environments in sync
Once on the Mac, keep using Git normally on the **same branch**
(`arena/01a07f45-spotvibe1-3`): commit legit iOS config changes (Podfile edits,
capability changes recorded in `project.pbxproj`) so Windows and Mac stay
aligned. NEVER commit `GoogleService-Info.plist`, `secrets.json`, or signing
files — they're already gitignored.

---

## Quick reference
| Item | From Git? | Action on Mac |
|---|---|---|
| Dart code, screens, logic | ✅ | Nothing |
| Xcode project / workspace / Podfile | ✅ | `pod install` |
| Firebase iOS plist | ❌ secret | Add from Firebase Console |
| Signing / team / certs | ❌ | Set in Xcode |
| secrets.json | ❌ secret | Copy over manually |
| AdMob iOS real id | ⚠️ test placeholder | Swap real id + SKAdNetwork |
